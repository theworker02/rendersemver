# rendersemver

Render structured JSON semver payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/rendersemver/

## Install / run

```bash
git clone https://github.com/theworker02/rendersemver.git
cd rendersemver
node src/cli.js
node --test
```
